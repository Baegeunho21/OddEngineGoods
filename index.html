01 설치

설치

인터넷 없이 설치되고, 설치할 때 PC에 있는 .NET으로 빌드해서 10~30초 걸립니다.

다운로드

CursorKeyring_Setup.zip 3.6MB

압축 풀고 실행

압축을 풀고 CursorKeyring_Setup.exe를 실행합니다.

PC 보호 창이 뜨면

추가 정보 › 실행을 누르세요. 서명 없는 프로그램이라 처음 한 번 나옵니다.

설치

02 키링

키링

사이드바의 라이브러리, 내 키링, 만들기에서 다룹니다.

라이브러리

고르기

키링을 고르고 적용하기. 더블클릭해도 됩니다.

  • 이름, 제작자로 검색
  • 이미지나 키링 폴더 가져오기
내 키링

여러 개 잇기

추가를 누르면 아래에 하나씩 더 매달립니다.

  • 복제, 빼기
  • 줄 종류(끈, 실, 체인), 길이, 무게, 탄성
만들기

직접 만들기

이미지나 3D 모델로 만들어 라이브러리에 저장합니다. 폴더째로 공유할 수 있어요.

  • png, gif, jpg, bmp
  • OBJ, glTF, GLB, FBX, STL

못 박기

마우스를 멈추면 그 자리에 고정됩니다. 당겼다 놓으면 튕기고, 못을 클릭하면 다시 커서로.

벽

던진 키링이 부딪히는 경계. 화면 끝과 안 맞으면 설정에서 다시 측정하세요.

숨기기

Ctrl+Alt+K. 단축키는 설정에서 바꿀 수 있습니다.

03 피클병

피클병

기본 키링. 국물이 출렁이고, 던지면 깨집니다. 아래 옵션은 피클병을 골랐을 때만 나와요.

던지기

  1. 마우스를 크게 돌려서 속도를 붙입니다.
  2. 일정 속도를 넘으면 줄이 끊어집니다.
  3. 화면 끝에 세게 맞으면 깨지고 피클이 쏟아집니다.
  4. 5초 뒤(기본값) 새 병이 생깁니다.

04 스티커

스티커

사이드바의 스티커 탭이 보관함입니다. 보관함 그림을 끌어다 붙이고, 옮기고, 우클릭으로 순서를 바꿔 보세요. 더블클릭하면 떼어져요.

내 PC
과제
휴지통
사진
보관함
1

추가 이미지 추가 버튼, 드래그 앤 드롭, Ctrl+V. 배경은 자동으로 지우고 흰 테두리를 붙입니다.

2

붙이기 창 밖 바탕화면에 놓으면 붙습니다. 창 안에 놓으면 취소, 더블클릭하면 화면 가운데.

3

순서 나중에 붙인 스티커가 위로 올라옵니다. 우클릭 메뉴로 앞으로·뒤로 보낼 수 있어요. 위치와 순서는 다음 실행 때도 그대로예요.

조작동작
Alt + 드래그이동
Alt + 휠크기
Alt + Ctrl + 휠회전
Alt + 우클릭앞으로·뒤로 보내기, 떼어내기, 복제, 초기화
편집 모드Alt 없이 이동, 휠로 크기

키링은 항상 스티커 위에 있습니다. 스티커는 아이콘 뒤나 모든 창 맨 아래에만 붙어서 다른 창도, 키링도 가리지 않아요.
